# Project Rules & Workflow Guidelines

## Implementation Planning Protocol

1. **Plan Before Execution**:
   - Before writing or editing code for non-trivial features, refactoring, or bug fixes, formulate a clear, structured implementation plan.
   - Outline the root cause or goal, the specific files to be created or modified, the step-by-step technical approach, and the verification strategy.

2. **Work Strictly According to the Plan**:
   - Execute the planned steps systematically in order.
   - Keep progress aligned with the plan and verify each milestone before concluding.
   - If an unexpected error, constraint, or blocker requires diverging from the plan, communicate the adjustment clearly before proceeding.

3. **Verify Each Step**:
   - Validate changes with unit tests, syntax checks, or live service verification before declaring the task complete.
